GPS Rasgan Fees — APK Build

Important:
The current environment does not contain the Android SDK/Gradle toolchain needed to compile an APK directly here. This project includes a GitHub Actions workflow that builds the installable debug APK automatically.

Easiest method:
1. Upload this project to a GitHub repository.
2. Open the repository's Actions tab.
3. Select "Build GPS Rasgan Fees APK".
4. Press "Run workflow".
5. When the job finishes, open the run and download the artifact named "GPS-Rasgan-Fees-APK".
6. Inside it is app-debug.apk. Install that APK on Android.

Firebase configuration:
app/google-services.json is already included for the configured Firebase Android app.

Note:
The APK is a debug build for testing/initial deployment. For Play Store or a production release, create a release signing key and build a signed release APK/AAB.
